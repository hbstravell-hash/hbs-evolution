# HBS Travel (اسم المشروع الداخلي على GitHub/Vercel: hbs-evolution)

منصة حجوزات سياحية عربية RTL لرحلات جورجيا، مبنية بـ Next.js 14 (App Router) و TypeScript و Tailwind CSS، وموجهة لعملاء دول الخليج. العلامة التجارية الظاهرة للزوار هي HBS Travel (نفس الاسم والشعار المستخدمين في الموقع الأساسي hbstravel.ge)، بينما "hbs-evolution" هو الاسم الداخلي لمستودع GitHub ومشروع Vercel فقط.

## التشغيل محلياً

npm install
npm run dev

## هيكل المشروع

- app/ صفحات الموقع (الرئيسية، الباكيجات، الوجهات، الأنشطة، صمم رحلتك، الحجز، الفنادق، الصفحات الأساسية، لوحة التحكم)
- components/ عناصر مشتركة (Navbar, Footer, WhatsAppButton, Accordion)
- lib/data.ts مصدر البيانات المركزي (الوجهات، الباكيجات، الفنادق، الأنشطة) - يتضمن الآن روابط صور حقيقية من Unsplash (مصدر مجاني الترخيص) بدلاً من المربعات الرمادية
