# HBS Evolution

منصة حجوزات سياحية عربية RTL لرحلات جورجيا، مبنية بـ Next.js 14 (App Router) و TypeScript و Tailwind CSS، وموجهة لعملاء دول الخليج.

## التشغيل محلياً

npm install
npm run dev

## هيكل المشروع

- app/ صفحات الموقع (الرئيسية، الباكيجات، الوجهات، الأنشطة، صمم رحلتك، الحجز، الفنادق، الصفحات الأساسية، لوحة التحكم)
- - components/ عناصر مشتركة (Navbar, Footer, WhatsAppButton, Accordion)
  - - lib/data.ts مصدر البيانات المركزي (الوجهات، الباكيجات، الفنادق، الأنشطة)
